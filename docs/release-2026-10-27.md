# 大制造工作台首版发布记录

2026 年 10 月 27 日，大制造工作台已部署到 [Agent 平台](https://agent.orbbec.com.cn/manufacturing)。初始开放平台 owner/admin，沿用平台登录、侧栏和页面外壳。真实账号登录后的浏览器验收由用户完成。

## 已发布功能

内部业务包括自研相机（含数采相机）、3D 打印机；外部业务包括 OEM 代工代料。分组、业务线、名称、排序、启停和环节模板通过稳定标识配置维护。

页面以流程总览和环节工作区组织。每个业务线、环节独立保存现状、待办、参与方、设计/BOM 等交接资料及系统关系，支持保存冲突提示、任务重试幂等和草稿离开保护。知识说明与协作关系默认折叠，初始企业现状为空。

ERP、MRP、MES 当前支持关系登记，尚未验证真实连接。接入真实数据需要补充系统厂商、接口、访问方式及数据责任。

## 回滚与发布证据

切换前已用从未启动、无挂载、无外加环境的旧镜像 probe 验证原 37 项 Compose 输入能够重现当时 API 配置。旧镜像标签和候选镜像默认配置均在切换前固定，切换限定为 `platform-api`。脚本保留原完整链、运行快照、配置备份与失败自动恢复逻辑；不确定恢复时保留锁。

成功收据为私有发布目录中的 `cutover.json`，隔离验证为 `candidate-validation.json`；成功后 action/input 锁已释放。后续人工回滚应重新取得发布锁、使用完整旧链和相同环境，并保留制造 data 目录；有实际数据后，备份 SQLite 应使用在线 backup 或一致地处理 DB/WAL。

首轮预发布在切换前拦截了安全解包工具忽略目录模式的问题；校验源码摘要后修正为 0555/0444，保留失败记录。首轮候选通过后又补充资产 release 查询版本校验，防止切换期间不同版本资源被缓存到同一版本键；重新生成 r2 制品并完整通过 prepare、candidate 和 cutover。首轮目录保留证据，未切换生产。
