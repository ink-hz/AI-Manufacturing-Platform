# 可持续操作的制造演示数据

用户已要求用 mock 数据跑通整套工作台。本次将上一轮隔离验收中的流程能力转为当前线上 demo 数据集内可见、可继续操作的虚构业务。沿用当前页面、身份、权限、领域规则与模拟外部系统，不重复建设工作台。

## 数据与体验

提供六个【模拟】项目，覆盖自研相机、数采相机、3D 打印机、OEM 代工代料四条业务线：相机缺料待补齐，数采相机在产且含质量异常，打印机首件待验证，OEM 客供料与设计协同，部分交付订单，以及交付后售后改进。各项目停在可解释的不同阶段，至少一条完成订单到交付的链路；订单、版本、工单、计划、批次、SN、质量、出货与反馈均由真实领域服务关联。

使用虚构中文产品、客户、供应商与 DEMO 外部单号，材料配比、计量单位、测试限值具有业务意义，但不宣称实际产品规格或实际客户批准。历史证据与外部回执明确标注“模拟”。数量与阶段由领域服务计算，不写入伪造成功状态。

## 导入边界

一次性维护工具，显式传入现有 demo 数据集与目标用户 UUID，生产模式拒绝执行；不在应用启动时导入，不引入测试登录、测试时钟、浏览器自动化或真实外部系统调用。代码仅依赖生产领域包与标准库，不能依赖 tests 或从验收数据库复制。

维护使用标明模拟的独立服务身份与按项目的明确角色，不能冒充员工或客户。经可信平台目录确认的现有平台负责人获得新增模拟项目的 project_owner 与普通业务操作角色；不因平台管理员身份自动获得质量资格。质量演示历史由独立模拟角色生成，真实用户后续资格仍走已有成员配置。不得修改现有项目的成员或平台角色。

导入有固定版本与操作 UUID，保留持久化 manifest；完成后再次运行只读取并验证结果，不覆写用户编辑。部分失败显式停止并保留断点和原始失败，恢复须识别已经提交的操作，不使用数据库整库回滚覆盖并发写入。

## 验证与交付

本地临时库及服务端临时库验证六项目关联、非空台账、可继续操作、权限边界、重复导入不变与原有 sentinel 不变。线上导入前 SQLite 在线备份，导入后独立进程读取数据库并以现有查询/权限契约验证可见性、阶段、数量及完整性。原有工作台项目、用户草稿、平台配置、其他容器和 Nginx 均保留。结果报告区分模拟流程验收与真实工厂/ERP 验收。
