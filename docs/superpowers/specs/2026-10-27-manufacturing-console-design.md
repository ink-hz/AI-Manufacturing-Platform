# 大制造独立管理平台设计

用户已明确确认独立页面，并要求左侧导航、右上角用户信息。本设计将这一方向落实到现有产品；开发和上线沿用本次任务已有授权。

## 入口与布局

`https://agent.orbbec.com.cn/manufacturing` 直接呈现独立管理平台。路由在 Agent 的 AppShell 之外渲染，不出现 Agent 顶栏、侧栏、页脚、全景框架或重复外层卡片。仍复用原企业登录、服务和权限。

桌面布局为 232px 左侧业务导航、64px 顶栏和自适应主工作区。导航以奥比大制造品牌开头，分组展示工作台、制造项目、事项、系统协同、制造手册，使用图标、选中态和必要的真实事项计数。底部提供返回 Agent 平台。支持收起侧栏；窄屏改为可关闭抽屉，Escape、遮罩和焦点行为可操作。

顶栏展示当前模块及项目层级，右上角展示真实用户名、姓名首字头像及真实角色名称。账户菜单有返回 Agent 平台与退出登录。没有消息源或配置功能的按钮不放上来。退出失败留在当前界面并显示错误。

主区采用浅灰背景、白色业务面板、蓝色交互主色与克制的状态色。去掉旧标题横幅和横向主导航。首页显示工作摘要、正在推进的项目、需关注事项和动态；列表、项目阶段、工程资料、生产准备、交接记录使用现有业务功能。新建项目只保留一个清晰入口。项目详情及手册仍在同一平台框架内。

## 职责与接口

Agent 前端只负责企业身份、权限探测、资源生命周期、共享 Markdown 渲染与真实账户动作；制造前端负责独立壳、业务导航、草稿离开保护和业务界面。

挂载选项向后兼容扩展：`user?: {displayName: string; roleLabel: string}`、`onNavigatePlatform?: () => void`、`onLogout?: () => Promise<void>`。不向制造应用传入员工目录或用户令牌。已有 CSRF 仍仅供受保护 API 使用。挂载句柄新增可选 `updateUser?(user): void`，更新展示信息时保留业务组件状态、草稿和 Markdown 实例。用户名/角色只来源于现有 Account；无账号信息时显示“企业账号”，不编造人员。

返回平台与退出必须先经过现有草稿确认。用户确认丢弃后，在脏状态和 beforeunload/SPA 守卫同步清理后再触发外部动作，避免重复确认。异步账户操作禁止重复提交；挂载失效后不得触发旧回调。登录、权限不足、资源加载失败与重试均不落回 Agent 外壳。通讯录过期只读提示继续可见。

## 不变的业务边界

- 所有现有项目、演示数据、业务 API、数据库、权限和 CAS 契约继续保留。
- 制造手册保持整篇连续阅读，复用共享 Markdown/Mermaid；不修改手册原文。
- 查阅手册后保留草稿和滚动位置；项目切换、退出及账户变化继续清理各自资源。
- 不增加前端依赖，不新增 ERP/MRP/MES 接口，不展示虚构同步或通知状态。
- 不修改共享 Nginx；不获取员工 Session；浏览器验收由用户完成。

## 验证与交付

新增组件测试覆盖独立路由没有 AppShell、真实账号显示和原地更新、账户菜单及失败、草稿确认后外部动作只执行一次、侧栏导航/收起/抽屉。跑制造现有前端回归和 bundle 验证、平台受影响组件回归和生产构建。无需为纯样式编写镜像 CSS 的测试，也不重复无关后端全量套件。

独立评审后合并两仓主线，以准确主线提交构建版本化产物；沿用已有候选隔离验证、SQLite 一致性备份、API 容器单点切换和回滚链。核对生产私有资源、身份边界、运行提交及其他服务不变。页面视觉验收留给用户。
