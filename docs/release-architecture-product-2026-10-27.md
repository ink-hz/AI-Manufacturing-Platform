# 制造架构产品化 v0.4 发布记录

2026-10-27，已上线[大制造工作台](https://agent.orbbec.com.cn/manufacturing)，平台 owner/admin 刷新后可用。第一轮实现“工程资料与版本 → 交接回执 → 生产准备核对 → 缺项处理”，系统与数据归属贯穿其中。

后续用户明确要求添加 mock 数据，已单独导入[6 个演示项目及关联记录](demo-data-2026-10-27.md)。这是发布后的授权数据操作，不改变下表应用版本与维护链；下文“没有预填演示项目”描述的是发布时事实。

## 已上线操作

- 工作台仍以真实项目为主，增加待补资料、待接收回执和准备缺项，点击定位具体对象。项目汇总状态同时考虑当前必需核对。
- 项目详情增加工程资料、生产准备和交接记录。资料包可创建、编辑、提交核对、核对完成、退回、新建修订及作废；冻结后仍可逐项查看全部资料。
- 各接收方分别登记交出、接收、退回或撤销，接收要求修订匹配、凭据和事件时间。平台登记人、登记时间独立留痕。
- 准备核对在创建时固定执行范围与版本绑定，维护物料责任、校准、人员、首件和客户条件。缺项可创建关联问题；完成任务不自动视为条件满足。版本变更有明确替代流程，旧证据与问题可回看。
- 系统协同维护真实系统/载体、责任人和唯一有效的数据归属；系统详情可看相关对象及未完成交接，并直接处理。人工、文件、API 是登记方式，不能据此声称连接成功。

OEM 分别记录客户版本、厂内版本和批准依据。相机、数采相机、3D 打印机沿用可调整的业务线框架。外部批准与平台人工核对分开；没有对 ERP/MRP/MES 正式过账，没有向客户/供应商发送消息，没有预填生产演示项目。

制造手册保持一份完整文档连续阅读，原文未改动，仍复用平台 Markdown/Mermaid。正文唯一来源为 `docs/manufacturing-system-handbook.md`。
