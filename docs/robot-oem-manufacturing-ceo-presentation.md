## 第 2 页｜执行摘要：三个判断，一个请求

### 判断一：窗口期在量产前夜，只有 12–18 个月

- 全栈式机器人公司（有模型/数据/本体）正处 A/B 轮、量产前夜。
- 小批量阶段锁定客户，放量时换厂成本已高到换不动。

### 判断二：纯 OEM 也能建壁垒，靠体系不靠设计

- 不做 ODM/JDM——『不碰设计』恰是全栈客户最在意的中立承诺。
- 壁垒 = SN 级数据档案 + 标定能力 + 可复制的导入体系。

### 判断三：EX001 证明了痛点，也给了原材料

- DVT 250 台：后段达成率掉到 84%，根因是物料状态与测试环境。
- 沉淀 89 项问题库 + 40 站测试排布——体系 V1.0 的种子。

### 请求：批准三件事

- 组织：成立平台工程部，对『复用率』而非交付考核。
- 预算：灯塔项目刚性保留 15–20% 体系化工作量 + 测试台架投入。
- 人才：测试标定负责人 + AI Agent 平台负责人到位。

一句话：产品归客户，体系归奥比——把『接住任何一家全栈客户』的能力包做成可复制资产。

论证顺序：市场机会（P3）→ 竞争对位（P4）→ 实战依据（P5–6）→ 方案架构（P7–11）→ 路线图与投入（P12）→ 目标（P13）→ 决策与风险（P14）。

## 第 4 页｜竞争对位：四类对手，各有接不住的理由

比较维度从『组装报价』切换到『导入速度 + SN 档案 + 标定测试』。

| 对手 | 基因与现状 | 结构性短板 | 奥比打法 |
| --- | --- | --- | --- |
| 灵猴（博众系） | 已批量代工交付，整线集成体系 | 自产运动件——客户 BOM 被捆绑，利益冲突 | 双中立（不自产运动件/不碰设计）+ SN 档案 + 标定 |
| 钛虎 | 关节供应商 + 整机厂，代工是副业 | 整机身份与客户直接竞争 | 其关节反向纳入 AVL，中立身份对比 |
| 长盈 / 天机 | 3C 基因的组装产能 | 批次主键 MES，做不了单台机器人档案 | 比 NPI 速度与数据纵轴，不比组装报价 |
| 富士康 / 立讯 | 等 Optimus 级大单 | 不接千台级小批量 | 时间差：小批量阶段锁定，放量时切换成本已立起 |

共同点：没有一家同时具备『中立身份 + 单台数据底座 + 感知标定能力』——这是奥比的组合拳，也是本方案要建成的东西。

## 第 7 页｜方案总览：三大平台 + AI 加速层的分层架构

下层给上层供数据；AI 的竞争力 = 数据底座 × 知识库 × 嵌入流程深度。

客户价值：导入快（10–12 周）· 状态透明（门户自查）· 质量可溯（SN 档案）。

### AI Agent 加速层（Copilot 模式，人签核）

导入评审 · 物料侦探 · 测试归因 · 工艺问答 · ECN 影响分析 · 8D 复盘。

| 平台 | 原稿内容 |
| --- | --- |
| 平台一 · 数字化运营 | 收料建档 / 急料引擎 / IQC 状态机；齐套看板 / SN 过站 / ECN 双轨 |
| 平台二 · 能力复用沉淀 | 问题库→检查项→SOP 回流；导入数据包规范 / 工艺模块库 |
| 平台三 · 统一测试标定 | 四级测试架构（40 站）；测试引擎框架化 / 标定自研 |

数据底座：整机 SN 主键 · 标定参数/测试曲线为一等数据对象 · 多租户隔离（中立性的技术实现）。

护城河逻辑：对手可以买设备、挖人、降价，但『单台数据底座 + 跨客户知识库 + 感知标定』的组合没有一家能同时复制。

## 第 8 页｜平台一：数字化运营——基于现有系统集成补缺，不另起炉灶

底座已有：SAP / MRP / WMS / MES；未来补 SRM；只建机器人代工特有的五个缺口。

| 系统 | 原稿职责说明 |
| --- | --- |
| SAP | 财务/采购/库存核算 |
| MRP | 物料需求计划 |
| WMS | 仓储管理 |
| MES | 制造执行 |
| SRM（规划） | 客户供应商协同 |

### 五个补缺（机器人代工特有）

1. ① SN 档案层：MES 批次主键之上叠 SN 主键，标定参数/测试曲线挂档案。
2. ② 轻量收料端：WMS 前置，直发料/蜂巢柜扫码建档，急料标签联动 MRP 缺口。
3. ③ 状态可视层：IQC 状态机 + 齐套看板（T-3 预警）。
4. ④ ECN 双轨：试产轻通道走 MES 工单，量产走 SAP。
5. ⑤ 客户门户：多租户数据汇聚层，不动核心系统。

### 原则与节奏

- 复用现有主数据与流程，只补缺口——投入小、风险低、上线快。
- SRM 上线后：客户供应商纳入协同，直发料从『快递黑盒』变成在途可视。
- P1（0–3月）：收料端 + SN 过站 + 急料标签。
- P2（3–6月）：IQC/齐套/ECN 双轨。
- P3（6–12月）：客户门户 + SRM 协同。

验收：物料状态在线率 100% · 急料响应 ≤2h · 『到现场问』归零 · 不新增一套独立系统。

## 第 9 页｜平台二：能力复用与沉淀——新人做老事，不出老问题

能力沉淀不是写文档，是让每个教训变成下个项目的强制关卡。

### 第一步：存量清算（1 个月）

- EX001 89 项问题逐条建库：问题/根因/对策/可拦截阶段。
- 物料 30 项 → 来料检验项。
- 结构 29 项 → DFM 检查表。
- AI 知识库化，评审自动比对。

### 三份标准资产（1–3 月）

- 《客户导入数据包规范》——只有物料清单？模板引导补齐。
- 《DFM 评审检查表》——全部来自真实问题。
- 《工艺模块库》七类模块——新客户 = 拼装 80% + 定制 20%。

### 制度保障

- 平台工程组 2–3 人，对复用率负责。
- 结案强制交付资产包，进 PM 考核。
- 复盘必答：『评审为什么没拦住』。
- 共性进平台、专属进项目成本，防止平台被单一客户带歪。

### 关键岗位：平台 1 号位画像（体系成败系于此人）

- 领域：具身机器人领域资深工程师，有工程量产经验（亲手把机器人从试产带到量产），最好有研发设计经历——除工艺外还能对客户设计提出合理性意见（以 DFM 建议形式输出，不介入设计决策）。
- 技能：跑过 EVT→DVT→PVT 全周期 · 研发+工艺+质量复合背景（能判断根因在设计还是制程）· 强结构化能力 · 会用知识库/AI 工具；特质：体系癖 · 延迟满足 · 较真不官僚 · 教练心态。
- 考核：问题复发率 / 模块复用率 / 导入周期 / DFM 建议采纳率；来源：优先从具身机器人公司（宇树/智元/银河通用生态）挖量产交付背景，内部机器人试产资深工程师次之，3C 系 NPI 平台背景仅作补充。

验收：同一问题跨项目复发率逐年减半 · 导入评审 2 周出报告 · 工艺模块复用率 ≥70%。

## 第 10 页｜平台三：统一测试标定平台——差异化所在，投入最重

EX001 已验证 40 站四级架构；客户差异收敛到『夹持接口 + 配置文件』。

### 四级测试架构

| 级别 | 原稿测试内容 |
| --- | --- |
| L1 单板 | 烧录 3min；测试 20min |
| L2 组件 | 电机/线束/标零；老化 1h |
| L3 半成品 | 组件联测 |
| L4 整机 | 30 项测试串；老化 2h + 标定 |

### 战略控制点

- 标定 100% 自研，单台 ≤20min。
- 3C 系对手最难复制的一环。

### 软件：统一测试执行引擎

- 一套引擎管 40 站：读总线/采图像/记曲线/判限/上传。
- 客户差异 = 配置文件，不是另写一套程序。
- 测试数据直通 SN 档案，曲线可追溯可对比。
- 分期：P1 引擎 MVP + 存量脚本迁移；P2 台架通用化；P3 自动化标定工站 + 对外开放测试服务。

### 硬件：台架分级通用化 + 环境先行

- L1 快换针床共用台体；L2 可调夹持老化架。
- L4 老化房按『适配 1.2–1.8m 本体』设计。
- 测试环境就绪 = 试产启动的前置关卡（硬性）。

  —— EX001 教训：老化环境晚 18 天，达成率掉到 84%。

- 资本开支：台架/老化房对外开放也能收服务费，不依赖自有代工量。

验收：测试脚本复用率 ≥60% · 新机型测试环境 ≤2 周 · 标定节拍 ≤20min/台 · 测试数据 100% 入 SN 档案。

## 第 11 页｜AI Agent 加速层：把三大平台的数据变成决策速度

对手的批次主键老 MES 喂不进单台数据——AI 原生设计是非对称武器。

| Agent 场景 | 作用 | 业务收益 |
| --- | --- | --- |
| 导入评审 | 图纸/BOM 自动比对 89 项问题库 + DFM 表 | 评审 2 周出报告，拦截率可量化 |
| 物料侦探 | 主动推送『料到未建档/缺口将阻塞』 | 急料从凭经验变全场盯防 |
| 测试归因 | 老化曲线异常预判 + 历史同类检索 | 测试从判良/不良升级为预判 |
| 工艺问答 | 扫码工位即问，答案带出处 | 新人上手周期显著缩短 |
| ECN 分析 | 自动生成影响清单（在制品/SOP/脚本） | 处理时长：2 天 → 半小时 |
| 8D 复盘 | 起草归因初稿，自动回流问题库 | 回流从制度负担变顺手动作 |

### 落地原则与组织

- Copilot 不做 Autopilot：输出带证据出处，人签核。
- 知识库先行：问题建库就是 Agent 训练场。
- 数据飞轮：每家客户让库厚一层，越用越准。
- AI 变革专家 = Agent 平台负责人，KPI 挂业务指标。
- 3 个月跑通前两个场景。

对外叙事：『AI 原生的机器人代工厂』——客户的算法团队天然信这套语言，本身就是商务差异化。
